# Celestial Dungeon

Небольшая космическая RPG-игра на Java с графическим интерфейсом Swing.

## Что внутри
- интерактивная карта 7x7
- управление мышью/кнопками и клавиатурой
- бои с врагами и коллекционирование реликвий
- механика исцеления и прогресса
- победа при сборе двух реликвий и открытии выхода

## Запуск

```bash
cd /workspaces/Test
mvn clean test
mvn exec:java
```

## Управление

- стрелки / WASD — движение
- Attack — атака рядом стоящего врага
- Heal — восстановление HP

Цель: собрать 2 реликвии и добраться до выхода в правом нижнем углу.
